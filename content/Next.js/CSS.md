<span style="color:rgb(255, 0, 0)">display: flex:</span> giúp cho các item hiển thị ngang
<span style="color:rgb(255, 0, 0)">flex-direction</span>: column/row; => giúp định hướng các item theo chiều dọc hay ngang
<span style="color:rgb(255, 0, 0)">justify-content: flex-start/- flex-end/- center/- space-between</span> => giúp căn chỉnh trên main axis
<span style="color:rgb(255, 0, 0)">align-items</span>: cũng có 5 phần tử như justify-content bao gồm flex-start/flex-<span style="color:rgb(255, 0, 0)">end/center/stretch/baseline </span>=> giúp căn chỉnh theo cross axis
Main axis theo ngang hay dọc phụ thuộc vào flex-direction: column/row
